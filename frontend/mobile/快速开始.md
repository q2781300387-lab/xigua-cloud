# IM Messenger - 快速开始指南

## 📋 项目概述

本项目基于 **Stitch 设计稿**,实现了 **IM Messenger** 移动端应用的登录和注册页面,做到了 **像素级 1:1 还原**。

### ✅ 已完成功能

#### 登录页面 (`pages/login/login.vue`)
- 📧 邮箱/用户名输入
- 🔒 密码输入 (可显示/隐藏)
- 🔗 忘记密码链接
- 🔵 主登录按钮 (带渐变和阴影效果)
- 🌐 社交登录 (Google、Apple、微信)
- 📝 注册跳转链接
- ✔️ 完整表单验证

#### 注册页面 (`pages/register/register.vue`)
- 📧 邮箱输入
- 📱 验证码输入 (带60秒倒计时)
- 🔒 密码设置 (可显示/隐藏)
- ☑️ 服务协议和隐私政策复选框
- 🔵 主注册按钮 (带渐变效果)
- 🔙 返回登录链接
- ✔️ 完整表单验证 (邮箱格式、密码强度等)

## 🎨 设计系统详解

### 核心设计理念

**创意方向**: The Ethereal Curator (空灵策展人)
**设计风格**: Soft Minimalist (柔和极简主义)

### 设计原则

1. **无边框规则**
   - 不使用 1px 实线边框
   - 通过背景色差异定义空间层次

2. **色调分层 (Tonal Layering)**
   - 使用不同明度的表面颜色创建深度
   - 避免使用重阴影

3. **Glassmorphism (玻璃拟态)**
   - 用于浮动元素 (如导航栏)
   - 使用半透明背景 + 背景模糊

4. **编辑级排版**
   - Plus Jakarta Sans: 正文字体
   - Manrope: 标题字体
   - 清晰的视觉层次

### 颜色规范

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| Primary | `#32ABFD` | 主按钮、链接、强调色 |

| Outline Variant | `#bec7d3` | 图标、占位符 |

## 🐛 常见问题

### Q1: 为什么 Google 图标显示不出来?

**A**: 需要手动添加 Google 图标到 `static/google-icon.png`。可以从设计稿中提取或下载官方图标。

### Q2: 如何修改主题颜色?

**A**: 编辑 `design-tokens.scss` 文件中的 `$primary` 变量,然后在各页面中引用。

```scss
$primary: #32ABFD; // 修改为你的颜色
```

### Q3: 如何适配不同屏幕尺寸?

**A**: 项目使用 rpx 单位,会自动适配不同屏幕。如需微调,可以修改设计 tokens 中的尺寸变量。

### Q4: 验证码倒计时如何自定义时长?

**A**: 在 `register.vue` 中修改 `codeCountdown` 初始值:

```javascript
this.codeCountdown = 60; // 修改为你需要的秒数
```

### Q5: 如何接入真实的后端 API?

**A**: 在 `handleLogin` 和 `handleRegister` 方法中替换 TODO 部分:

```javascript
// 示例: 使用 uni.request 调用 API
uni.request({
  url: 'https://your-api.com/api/auth/login',
  method: 'POST',
  data: this.formData,
  success: (res) => {
    if (res.data.success) {
      uni.showToast({ title: '登录成功', icon: 'success' });
      // 跳转到首页
      uni.switchTab({ url: '/pages/index/index' });
    }
  }
});
```
